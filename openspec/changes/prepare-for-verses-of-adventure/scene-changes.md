# Scene changes for Verses of Adventure

The playtest needs tiles for Glowmere Grotto and recaptures for Faerie's Brake, Ripper's Keep, Port Azure, Hidden Hills, Willowwatch Ridge, Stowaway's Step, Malaroth's Nesting Grounds and Soluna's Landing. This list is independent of task 5.2's outdoor lighting check.

## What was compared

Compared `Scenes/*.unity` in `variants/main/unity/ExportedProject/Assets` and `variants/playtest/unity/ExportedProject/Assets`. SHA-256 differed for all 49 shared scenes. Nothing was removed and `Glowmere` is the only new scene. Hash differences alone did not identify geometry changes. For example, after replacing GUIDs, the only text change in `Detention` was `NeverRain: 0`.

Resolved terrain, mesh and navigation references through each rip's `.meta` files. Compared the decoded terrain height samples, holes, dimensions and paint buffers. The main rip stores terrain and NavMesh assets in binary and the playtest uses YAML, so file hashes are not comparable for those assets. Compared mesh vertex and index data, non-trigger collider shapes and transforms composed through their parent hierarchy. The counts below are serialized mesh filter/renderer pairs and non-trigger colliders, not unique mesh assets or visible triangles. They exclude character, rigidbody and spawn or point-of-interest marker hierarchies. Compared those markers, triggers and inactive objects separately. Compared NavMesh tile payloads without depending on tile order. For routes and placements, used the clean zone lines and map spawn rows. These are asset findings, not in-game route or collision checks.
