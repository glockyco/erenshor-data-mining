# Interactive Map Companion

See your game world update live on the [interactive world map](https://erenshor-maps.wowmuch1.workers.dev/map), either in a browser or through the optional in-game overlay.

## What it tracks

- Your character and facing direction
- SimPlayers in the zone
- Friendly NPCs and merchants
- Hostile enemies
- Companion pets

Tracking updates ten times per second by default. All live game data stays on your machine. The mod runs a local WebSocket server that the map connects to directly.

## Quick start

1. Install Interactive Map Companion through Lunaris.
2. Launch the game and log in with a character.
3. Open the [interactive world map](https://erenshor-maps.wowmuch1.workers.dev/map).
4. Enable **Live Mode** in the map sidebar.

## Configuration

The Lunaris config UI exposes the WebSocket port, update interval, overlay settings, and log levels. The default WebSocket port is `18585`.

## Installation

Install through Lunaris by opening the in-game mod browser and selecting Interactive Map Companion from the Erenshor Vault.
